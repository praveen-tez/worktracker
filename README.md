# Monthly Time Tracker

Nuxt 3 dashboard for monthly sprint tasks, OSG actions, activity logs, and portable exports.

## Run

```bash
npm install
npm run dev
```

## Google Sheets

Set `NUXT_PUBLIC_SHEETS_ENDPOINT` to a deployed Google Apps Script web-app URL. The app POSTs the complete tracker payload to that endpoint when **Sync to Sheets** is used. Until configured, the app persists data in browser local storage.
